# YC Startup School Notes 🚀

Structured and easy-to-follow notes from **Y Combinator's Startup School** course.

I created this repository while going through the course to capture the **key ideas, frameworks, and practical advice** from the lectures in an easy-to-revisit format.

These notes :
- Capture the key points from each lecture
- Focus on practical and actionable takeaways
- Stay close to the ideas and terminology used in the original lectures
- Revisit key takeaways without rewatching entire lectures


> These are personal learning notes and are not a replacement for the original YC Startup School course.
